## Permanent Rules

- **Never act without explicit user approval first.** Always present your analysis and proposed actions, then wait for the user to say "go" or give the green light before executing. This applies to ALL actions: file edits, commits, pushes, PRs, discussions, and any other external actions.
- **Never commit, push, create a PR, or perform any external action without explicit user approval first.** Always present what you plan to do and wait for the user to say "go" or give the green light before executing.
- **Never post comments, replies, or any content to GitHub (discussions, issues, PRs) without showing the draft to the user first and getting explicit approval.** Present the proposed text and wait for "go" before posting.
